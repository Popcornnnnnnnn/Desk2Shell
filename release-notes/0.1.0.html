Desk2Shell 0.1.0 Developer Preview

首个公开开发者预览版，将一次远程桌面会话转换为通过用户现有 Tailscale 网络工作的临时、仅公钥 SSH 连接。

  • 加密的一次性 enrollment 与独立配对码
  • Windows 端独立 SSH 服务、限定范围的防火墙规则
  • 自动过期、主动撤销和 Mac 端 SSH 验证
  • macOS 14+，Apple silicon

预览版边界：Mac App 与 DMG 已完成 Developer ID 签名和 Apple 公证；内嵌 Windows Bootstrap 暂未签名，Windows 可能显示 Unknown publisher 或被受管安全策略阻止。
